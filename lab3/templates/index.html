📖 СПРАВКА: Как пользоваться программой ▼
1. Ввод массива
• Ручной ввод: введите числа через запятую (например: 5, 3, 8, 1, 9)
• Загрузка из файла: нажмите кнопку "Выберите файл" и выберите .txt файл с числами
• Случайный массив: нажмите кнопку "🎲 Случайный массив" для генерации 10 случайных чисел
2. Сортировка
• Нажмите кнопку " Отсортировать"
• Результат появится в поле ниже с указанием времени выполнения
• Исходный и отсортированный массивы сохраняются для дальнейшей работы
3. Сохранение в базу данных
• После сортировки нажмите "💾 Сохранить в БД"
• Массив сохранится в вашем личном кабинете
• Все сохранённые массивы видны в разделе "Мои сохранённые массивы"
4. Работа с сохранёнными массивами
• Загрузить сохранённые — показать все ваши сохранённые массивы
• Использовать — подставить массив в поле ввода и автоматически отсортировать
• Удалить — удалить массив из базы данных
• 🧹 Очистить таблицу — скрыть таблицу (не удаляет данные)
